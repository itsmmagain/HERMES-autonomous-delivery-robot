# HERMES Project Proposal

## Title
HERMES: Autonomous Mobile Robot for Secure Inter-Office Document Delivery

## Problem Statement
Sensitive documents in office environments are often moved manually, creating delays and increased risk of unauthorized access. HERMES addresses this by autonomously transporting documents in a locked vault using local, offline decision-making.

## Objectives
1. Design and build a differential-drive mobile platform for office delivery.
2. Implement secure vault control with RFID + keypad authentication.
3. Deploy ROS 2 SLAM and Nav2 for autonomous navigation.
4. Integrate vision-based proximity monitoring for security alerts.
5. Validate reliability, safety, and access control through office trials.

## Scope
- Indoor office corridor and room-to-room delivery
- Air-gapped operation (no remote/cloud dependency)
- Payload-focused design up to 5 kg
- Local mission planning and authentication workflows

## Expected Deliverables
- Working autonomous robot prototype
- Full technical documentation and wiring references
- Source code for ROS 2, Arduino, and Python modules
- Validation procedure and final performance report
