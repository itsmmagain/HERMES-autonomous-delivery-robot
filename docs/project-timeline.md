# Project Timeline (12 Weeks)

## Week 1–2: Literature Review & Proposal Defense
- Finalize problem framing and objectives
- Define measurable success criteria
- Defend proposal

## Week 3–4: Component Procurement & Hardware Assembly
- Acquire mechanical/electrical components
- Build chassis, mount motors, integrate battery and housing

## Week 5–6: Circuit Integration & Microcontroller Wiring
- Wire drive electronics, encoder lines, RFID, keypad, and lock driver
- Verify signal integrity and power distribution

## Week 7–8: ROS 2 Setup, SLAM & Nav2 Configuration
- Configure Ubuntu and ROS 2 on Raspberry Pi
- Bring up LiDAR, mapping, localization, and navigation stack

## Week 9–10: Feature Implementation
- Integrate RFID + keypad authentication workflow
- Deploy MobileNet-SSD monitoring pipeline
- Tune PID loops under representative payloads

## Week 11–12: Testing, Trials & Final Defense
- Execute route and safety tests in office-like environment
- Record validation metrics and failure cases
- Final report and defense preparation
