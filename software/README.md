# Software

This directory groups the software stack by execution environment.

## Contents
- `ros2/`: ROS 2 packages for mapping, localization, and navigation
- `arduino/`: low-level firmware for drive control and secure IO
- `python/`: vision and orchestration scripts

## Target Platform
- Ubuntu 22.04
- ROS 2 Humble Hawksbill
- Python 3.x
- C++ (ROS 2 nodes)
- Arduino C/C++
